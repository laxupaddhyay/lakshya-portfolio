# Lakshya Upaddhyay — Portfolio

A frontend-only software engineering portfolio built with React, TypeScript, Vite, and Motion. It presents selected projects, experience, skills, and contact details. Project cards link to their public GitHub repositories.

## Requirements

Node.js 20.19+ or 22.12+.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site is static and requires no backend or paid services. Theme choice is stored in the visitor's browser.
